## 注意事項
- 大まかな仕様についてはProject_debuff2D.md参照されたし
- 新しくUIを利用するSceneを作成する場合はPrefab/UIからCanvasTemplateを使ってください。
- また、GameビューからAspectを16:9に設定してください。
- 他の人が利用するであろうスクリプトやPrefabを作成したら、できればそのスクリプトやPrefabを保存してあるフォルダ内にその仕様をマークダウンファイルに書いたものを作ってもらえると意思疎通がはかどって助かります。
- 機能の動作確認はSampleSceneで行えるようにしてください。
